How I handle donor data

  • Least privilege. Access only to the fields a report needs, reviewed when a project ends.
  • Personal data in extracts. Constituent IDs instead of names where possible, no home addresses or birthdates unless the request needs them, and extracts deleted on a set date.
  • Secure transfer. MIT-approved shared drives and vendor portals, never email attachments of donor lists.
  • Audit trail. Every list and report saved with its query, date, requester and row count, so it can be rebuilt.
  • No donor data in samples. Everything in this work sample is synthetic.
